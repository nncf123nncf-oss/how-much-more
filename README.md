# あと何円稼げばいい？（how-much-more）

目標額・今までの売上・期間を入れると、残りの金額を「1か月・1週間・1稼働日あたり」に直して出す静的ページです（100日100プロダクト Day074）。単価を入れれば必要件数も出ます。

- 入力した数字はブラウザの中だけで処理し、サーバーには送信せず、保存もしません（通信は閲覧数の計測のみ）
- AIは使っていません（四則演算と日付の差のみ）
- 手取りではありません。「同じペースが続いた場合」は単純な計算で、先の見通しではありません

## 使い方
`index.html` をブラウザで開きます。ビルド不要（1ファイル）。

## 開発用（source/）
- `run-checks.js`: 計算の検算（`node source/run-checks.js`）
- `browser-checks.js` / `cdp.js`: 実ブラウザ（Chrome headless）での検算
